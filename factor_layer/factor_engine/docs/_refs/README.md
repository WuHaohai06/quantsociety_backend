# `docs/_refs` — 外部参考摘录

本目录用于存放 **从外部文档、研报、网页摘录的参考片段**（若存在），**不构成** factor_engine 的 **规范正文**。

### 协作者速览（约 1 分钟）

1. **本目录在干什么**：**备查摘录**；**实现与验收**以 **`docs/operators_semantics.md`**、**ADR**、**源码与 `tests/`** 为准。
2. **何时打开**：对照外部研报/旧文档时；**不要**把本目录当 DSL 或算子语义的唯一来源。

## 使用约定

| 约定 | 说明 |
|------|------|
| **优先级** | 行为以 **`docs/operators_semantics.md`**、**ADR**、**源码与测试** 为准。 |
| **版权** | 摘录请注明来源与日期；勿将受版权保护全文长期存放于仓库（遵守贵司合规）。 |
| **维护** | 若与主文档重复，以 **`docs/` 根目录** 下文件为准，本目录仅作 **备查**。 |
